# NOTICE

MapleForge is an independent, non-commercial research project.

## What this repository is

A from-scratch C# implementation used to study how a legacy real-time game server
protocol can be reconstructed and verified. The engineering interest is in
Clean/Hexagonal architecture, evidence-backed protocol documentation, and automated
verification of wire behavior — not in operating a game.

## What this repository is not

- It is **not** affiliated with, authorized by, or endorsed by any game publisher.
- It contains **no** game client, game assets, WZ data files, artwork, audio, or
  publisher binaries. Only original C# source, documentation, and small
  handshake-stage packet fixtures are included.
- It is **not** operated as a playable service, and this repository contains no
  instructions for operating one.
