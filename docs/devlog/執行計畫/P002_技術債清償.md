## T1: ENTER_CASH_SHOP — 完整模式切換

### Java 架構
客戶端斷開 channel server → 重連到獨立 CashShopServer（不同 port）。
- `InterServerHandler.EnterCashShop`: 保存角色、清地圖/buff、送 `getChannelChange(CashShopServer IP:port)`
- 客戶端斷線重連 → 送 `PLAYER_LOGGEDIN` → `CashShopOperation.EnterCashShop`: 重建角色、送初始化封包序列
- 初始化：`warpCS`(SET_CASH_SHOP) + `showCashShopAcc` + `showGifts` + `RefreshCashShop` + `sendShowWishList`
- 離開：`LeaveCashShop` 送 `getChannelChange(channel IP:port)` → 客戶端再斷線重連回 channel

### MapleForge 做法（單程序 reconnect）
利用**客戶端斷線重連**機制，不需模式切換：
1. 收到 `ENTER_CASH_SHOP` → 保存角色、移除地圖 → 記錄 `pendingCsTransition[characterId]` → 送 `getChannelChange(自己的 IP:port)`
2. 客戶端斷線重連 → 送 `PLAYER_LOGGEDIN` → 偵測到 pending → 進入 **CS packet loop**
3. CS packet loop 處理：`CASH_SHOP_OPERATION`(0xE6)、離開商城
4. 離開 → 清 pending flag → 送 `getChannelChange(自己)` → 客戶端再重連 → 正常 channel 登入

### 需新增/修改
- `V113ChannelConnectionHandler.cs`: ENTER_CASH_SHOP 流程 + PLAYER_LOGGEDIN 分流 + CS loop
- `V113CashShopPackets.cs`: 補 `WarpCS`(SET_CASH_SHOP 初始化封包，含角色資訊+商品目錄) + `ShowGifts` + `ShowWishList`
- 可能新建 `V113CashShopSessionHandler.cs` 獨立 CS mode handler
- `MapleServerHost.cs`: 注入 `CashShopService`（如尚未）

### 風險
- `warpCS` 封包結構複雜（角色完整資訊+商品目錄+hex 常量），需仔細對照 Java `MTSCSPacket.warpCS`
- 客戶端 reconnect 可能有 timing 問題

## T2: USE_SKILL_BOOK — ISkillBookCatalog

### Java 邏輯 (`InventoryHandler.UseSkillBook`)
1. `MapleItemInformationProvider.getSkillStats(itemId)` → 從 Item.wz 讀：
   - `success` (成功率 %)
   - `reqSkillLevel` (需要的當前技能等級)
   - `masterLevel` (成功後設定的 master level)
   - `skillid0`, `skillid1`, ... (適用技能 ID 列表)
2. 遍歷 skillId，找 `skillId / 10000 == player.job` 的
3. 檢查 `currentSkillLevel >= reqSkillLevel` 且 `currentMasterLevel < masterLevel`
4. 機率 roll → 成功則 `changeSkillLevel(skill, currentLevel, masterLevel)`
5. 消耗道具 → 廣播 `useSkillBook` 封包
6. 適用 itemId 前綴：228x (技能書) / 229x (精通書)

### MapleForge 實作
1. **Core** `Maple.Core/Skills/`:
   - `SkillBookDefinition` record: `(int ItemId, int[] SkillIds, int SuccessRate, int ReqSkillLevel, int MasterLevel)`
   - `ISkillBookCatalog` 介面: `SkillBookDefinition? GetByItemId(int itemId)`
2. **Content** `Maple.Content/Skills/`:
   - `JsonSkillBookCatalog` (仿 `JsonCashItemCatalog` 模式)
   - 需準備 JSON 測試資料（從 Item.wz 228x/229x 萃取）
3. **Adapters**: 重寫 `HandleUseSkillBookAsync`:
   - 注入 `ISkillBookCatalog`
   - 查 catalog → 職業匹配 → 等級檢查 → 機率 roll → 更新 masterLevel
4. **Core 前提**: 確認 Player 有 skill master level API（可能需補 `ChangeSkillMasterLevel`）
