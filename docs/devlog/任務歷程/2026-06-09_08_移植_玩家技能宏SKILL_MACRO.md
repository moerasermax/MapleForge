## 🎯 目標（執行前先寫死，過程不偷改）

移植舊 Java `PlayerHandler.ChangeSkillMacro` 與 `MaplePacketCreator.getMacros`，讓 MapleForge 能保存並在登入後送出玩家技能宏設定。

完成判準：

1. Core/Character 有版本無關的 skill macro 文件模型與變更方法；不出現 v113 opcode 或 byte layout。
2. Adapters.V113 解析 `SKILL_MACRO(0x68)`：`num + name/shout/skill1/skill2/skill3...`，macro position 依 Java 使用 loop index。
3. Adapters.V113 編碼登入後 `SKILL_MACRO(0x7A)`，只送非空 macro，欄位順序對齊 Java。
4. Channel handler 收到變更後更新角色文件並持久化；登入後若角色有 macro 則送 `SKILL_MACRO`。
5. 補針對性測試與完整 project checks。
6. 同步 protocol spec、任務追蹤、進度日誌與任務歷程索引。

不做範圍：

- 不驗證 skill id 是否已學會；舊 Java 此 handler 也只保存客戶端送來的 macro。
- 不處理技能施放、cooldown、buff 語義。
- 真客戶端 UI smoke 本輪不跑，待功能批量完整後再做。
