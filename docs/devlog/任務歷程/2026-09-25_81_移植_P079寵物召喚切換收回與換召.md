## 📋 背景與查證

- 掃描：`V113*Packets.cs` public 方法外部零參照且檔內僅定義一次 → 8 個候選（`CreateGuildAlliance`、`RemoveTownPortal`、
  `SpawnDoor`、`SpawnPortal`、`MerchantBuyError`、`RemovePet`、`MarriageRingLook`、`SpawnSummon`），本 P 處理 `RemovePet`，其他逐一另開 P。
- Java `MapleCharacter.spawnPet`：`pet.getSummoned()` → `unequipPet(pet, false, true)`；否則若沒有「寵物隊長」技能
  （8/10000018/20000024）且 slot 0 已有寵物 → `unequipPet(getSummonedPet(0), false)` 再召喚新寵物。
- Java `unequipPet`：`map.broadcastMessage(this, showPet(this, pet, true, hunger), true)`（含自己）→ `petStatUpdate` → `enableActions`。
  `unequip=true` 時的寵物裝備自動脫除，MapleForge 沒有寵物裝備欄，不移植；`petStatUpdate` 召喚端同樣未送，列候選。
- MapleForge 只支援單一寵物（`PetService._activePets` 以角色 ID 為鍵），所以換召一律走「先移除再召喚」。
