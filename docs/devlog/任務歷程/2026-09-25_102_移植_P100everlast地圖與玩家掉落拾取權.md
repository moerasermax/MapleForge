同一條 Java 判斷式，一起修。完成判準：旗標解析、拾取權與過期規則有測試，build 0/0，全測試無退化。

## 📋 背景與查證

- Java `MapleMap.spawnMesoDrop`（1775 行）與 `spawnItemDrop`（1957 行）：`if (!everlast) { registerExpire(120000); [registerFFA(30000)] }`；
  `spawnMobDrop`/`spawnMobMesoDrop` 不看 everlast，照常過期。MapleForge 對應：玩家丟楓幣 `TryDropMeso`（`PlayerDrop = true`），怪物掉落 `SpawnDropsFromMonster`。
- Java `InventoryHandler.ItemPickup`（2337-2344 行）：`owner != chr && ((!playerDrop && dropType == 0) || (playerDrop && everlast))` → 擋；
