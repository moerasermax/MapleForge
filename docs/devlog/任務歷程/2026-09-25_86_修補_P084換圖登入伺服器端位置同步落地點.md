- Java 登入：`loadCharFromDB` 以 `initialSpawnPoint` 取 portal，找不到 `getPortal(0)`，`setPosition(portal.getPosition())`。

  的 SpawnPoint byte 同義；登入用 `chr.SpawnPoint`。
