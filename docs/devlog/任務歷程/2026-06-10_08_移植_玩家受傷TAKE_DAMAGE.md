## 目標

移植舊 Java `TAKE_DAMAGE` 的最小可驗證主幹：解析玩家受傷封包、扣除 HP、更新本人血量，並把受傷動畫廣播給同地圖玩家。

完成判準：

1. v113 adapter 接上 `TAKE_DAMAGE(0x29)` parser。
2. Core 仍只保存版本無關受傷語義，不放 opcode/byte layout。
3. Channel handler 扣 HP 並送 `UPDATE_STATS` / `DAMAGE_PLAYER`。
4. 有 parser/封包或 handler 周邊單元測試。

## 執行歷程

- 建檔定目標。
- 對照舊 Java `PlayerHandler.TakeDamage` 與 `MaplePacketCreator.damagePlayer`，確認 `TAKE_DAMAGE=0x29`、`DAMAGE_PLAYER=0xB8`。
- 新增 `V113PlayerDamagePackets`，解析怪物傷害與地圖傷害兩種 layout，並編碼無反傷分支 `DAMAGE_PLAYER`。
- Channel handler 接上受傷流程：驗證傷害值、怪物 oid、扣除玩家 HP、回 `UPDATE_STATS(HP)`，再對同圖其他玩家廣播受傷動畫。
- 補 Adapter parser/encoder 測試。
