## 📋 背景與假設

- 根因：C# `HealHp` 等以基礎 `MaxHp` 為上限 → 穿 +HP 裝備或神聖之火時伺服器補血補不滿、HpRate 算少。
- Java 神諭：`PlayerStats.recalcLocalStats:253-901`（`localmaxhp_ = getMaxHp() + Σequip.getHp()`、`+= percent_hp*…/100f`、`+= buff/100.0*…`、`min(30000, abs(max(-30000, …)))`）、`setHp:136`（上限 localmaxhp）、`MapleStatEffect.calcHPChange:1334`（hpR × getCurrentMaxHp）、`doBerserk:1598`、`updatePartyMemberHP:2851`。
- Java int 複合指定（`int += double`）會截斷，C# 照做。
- Java 潛能的 `localmaxhp += pot.incMHP` 寫到欄位而非暫存（之後被覆蓋，等於無效）——記錄，未來做潛能時照抄。
