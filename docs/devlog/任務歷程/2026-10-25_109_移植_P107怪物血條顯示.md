4. build 0/0、全 8 專案 0 failed、三本帳。

## 📋 背景與假設

- 原計畫 P107 做武陵能量；查 Java 發現能量累加掛在 `MapleMonster.damage:365` 的 HPDisplayType 2 分支，而 C# 整個血條分派都不存在（`MobStats.HpDisplayType` 有值但零使用）。
- Java 神諭：`MapleMonster.damage:262-390`、`MapleLifeFactory:135-220`、`MobPacket.showMonsterHP:104`/`showBossHP:114`/`damageFriendlyMob:58`/`damageMonster:43`；`send.properties` `SHOW_MONSTER_HP=0xF3`、`BOSS_ENV=0x87`、`DAMAGE_MONSTER=0xEF`。
- `damageMonster`（display 0）在 Java 只用於持續傷害（`MapleMonster:1290/1441`）、反彈（`PlayerHandler:377`）與 GM 指令——玩家攻擊不送。
- C# 既有 `GetHpDisplayType` 偏差：王一律回 0、未讀 tagColor、無 -1。
