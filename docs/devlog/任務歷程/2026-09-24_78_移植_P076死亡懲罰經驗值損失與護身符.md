## 📋 背景與查證

- Java `PlayerStats.setHp`：`oldHp > hp && !isAlive()` → `enableActions` + `setCheckedAmulet(true)` + `playerDead()`；
  `checkedAmulet` 在這條路徑一定是 true，所以有護身符一定會消耗。
- Java `playerDead` 經驗值區塊：`job ∉ {0,1000,2000,2001,3000}` 時：`getItemQuantity(5130000)` > 0 → `removeById(CASH,5130000,1)` +
  `useCharm(剩餘, 0)`；否則 5130002 同款；否則 `diepercentage = town || RegularExpLoss ? 0.01f : (float)((job/100==3 ? 0.08f : 0.2f) / luk + 0.05)`，
  `exp = max(0, exp - (long)(expForLevel * diepercentage))`。最後一律 `updateSingleStat(EXP)`。`luk` 是基礎 LUK（`PlayerStats.getLuk()` 回 `luk` 欄位）。
- Java `MTSCSPacket.useCharm`：`SHOW_ITEM_GAIN_INCHAT(0xC7)` + 6 + 1 + charmsLeft + daysLeft。
- 不在本 P：靈魂之石復活、事件副本 `playerKilled`、`dispelSkill`/取消變身/騎寵/召喚/傀儡、`checkFollow`、裝備耐久、
  金字塔、強效護身符的 `check_EffectAmulet` 旗標效果。
