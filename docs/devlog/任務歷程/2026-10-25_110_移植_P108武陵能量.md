## 📋 背景與假設

- Java 能量欄位只在建構時歸零（`MapleCharacter:211`），不寫 DB → C# 不持久化。
- Java 攻擊順序：廣播攻擊封包 → `applyAttack`（內含武陵判斷）→ 傷害。C# 近戰在廣播後、套傷害前判斷；遠程/魔法在套傷害前判斷（C# 這兩條本來就是先算後廣播）。
- 多目標命中時 Java 每次 `damage` 都送一包；C# 每個 hit 送一包、值為該次累加後的值，相同。
