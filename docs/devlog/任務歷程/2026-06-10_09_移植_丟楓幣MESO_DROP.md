## 目標

移植舊 Java `PlayerHandler.DropMeso` 主幹，支援玩家從背包丟出 10~50000 楓幣，扣款並生成地圖楓幣掉落。

完成判準：

1. v113 adapter 接上 `MESO_DROP(0x58)` parser。
2. 使用既有 `MapDrop` / `DropItemFromMapObject` 廣播地圖楓幣。
3. 無效金額或餘額不足時放行不改資料。
4. 有 parser 或 domain/packet 測試覆蓋。

## 執行歷程

- 建檔定目標。
- 對照舊 Java `PlayerHandler.DropMeso`，保留 10~50000 楓幣限制、未存活/餘額不足放行不改資料的主幹。
- `DropService.TryDropMeso` 新增玩家丟楓幣路徑，扣除角色楓幣並建立 player-drop 型 `MapDrop`。
- `V113DropPackets.ParseMesoDrop` 解析 `tick + meso`；Channel handler 成功時回 `UPDATE_STATS(MESO)` 並廣播 `DROP_ITEM_FROM_MAPOBJECT`。
- 補 Application domain 測試與 Adapter parser 測試。
