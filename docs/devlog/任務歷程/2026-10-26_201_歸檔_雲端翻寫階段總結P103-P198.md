## ⚠️ 已知風險（需真機確認）

- **時間編碼**：既有 `AddItemInfo` 的 `GetTime` 遇到正數期限會寫成「現在時間」，`-1` 的常數也和 Java 的 `getTime`（MAX_TIME）不同。新的寵物編碼器照 Java 寫，`V113PetPackets.UpdatePet` 仍用舊慣例，兩者並存。
- **新封包未驗證**：P194 的教學 UI、P198 的寵物格式都是照 Java 版型寫的，尚未用真客戶端驗證。
