## 🎯 目標（執行前先寫死，過程不偷改）

P075 查證衍生：Java `PlayerStats.setHp`（非 silent）每次 HP 變動都 `updatePartyMemberHP`，對同地圖、同頻道隊友送血條；MapleForge 只在
組隊操作/進圖時同步一次，受傷、自然回血、世界 tick 扣血/回血都不更新隊友畫面的血條。完成判準：主要 HP 變動點接上、測試綠燈、
build 0/0、全測試無退化。

## 📋 背景與查證

- Java `MapleCharacter.updatePartyMemberHP`：`party != null` → 對 `getMapid() == 本人地圖 && getChannel() == 本頻道` 的隊員
  `sendPacket(updatePartyMemberHP(id, hp, currentMaxHp))`。
- Java `setHp(newhp, silent=false)` 呼叫 `doBerserk()` + `updatePartyMemberHP()`；`addHP`（怪物傷害、地圖扣血、龍之魂）與 `healHP`
  （自然回血、回復術）都走這條。
- MapleForge 每頻道一個 process，`IMapSessionRegistry` 只含本頻道玩家 → 同地圖過濾即等於 Java 的同圖同頻道。
- 本 P 接上的點：`TAKE_DAMAGE`、`HEAL_OVER_TIME`、世界 tick 地圖扣血（P075）、龍之魂（P093）、回復術（P092）。
  藥水等道具回血、技能 HpCon 扣血等其他 HP 變動點尚未接（候選）。
