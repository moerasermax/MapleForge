## 🎯 目標（執行前先寫死，過程不偷改）

對照 Java `handleCooldowns` 的 `canRecover(now)` + `doRecovery`：RECOVERY buff 生效期間每 5 秒回 `x` HP 並顯示回血特效，滿血取消 buff。
MapleForge 的技能目錄已產生 RECOVERY statup，但沒有任何週期效果。完成判準：測試綠燈、build 0/0、全測試無退化。

## 📋 背景與查證

- Java `registerEffect`：`effect.isRecovery()` → `prepareRecovery()`（`lastRecoveryTime = now`）。
- Java `canRecover(now)`：`lastRecoveryTime > 0 && lastRecoveryTime + 5000 < now`（嚴格小於）。
- Java `doRecovery`：`prepareRecovery()`；`hp >= currentMaxHp` → `cancelEffectFromBuffStat(RECOVERY)`；否則 `healHP(x, true)`。
- Java `healHP(delta, true)`：`addHP(delta)`（HP 更新）→ `showOwnHpHealed(delta)` 給本人 → `showHpHealed(id, delta)` 給同圖其他人。
- Java 在 `handleCooldowns` 的 `if (chr.isAlive())` 區塊內呼叫。
- 差異：Java 用 `getCurrentMaxHp`（含 Hyper Body 等 buff），MapleForge 目前只有基礎 MaxHp。
