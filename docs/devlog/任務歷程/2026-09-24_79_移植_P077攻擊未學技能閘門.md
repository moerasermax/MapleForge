## 📋 背景與查證

- Java `AttackInfo.getAttackEffect`：`isMulungSkill || isPyramidSkill` → 等級強制 1；否則 `skillLevel <= 0` → null。
  等級 > 0 時 `Skill.getEffect(level)` 只要有 effect 就不會回 null（超過上限回最後一級）。`display > 80` 無動作
  autoban 分支屬另一件反作弊，不移植。
- `closeRangeAttack`/`rangedAttack`：`attack.skill != 0` 才查 effect，null 則 return（在種類檢查之後、冷卻之前）。
- `MagicDamage`：沒有 `skill != 0` 保護，effect null 則 return（技能 0 也丟棄）。
- 技能等級：`chr.getSkillLevel(SkillFactory.getSkill(getLinkedSkill(attack.skill)))`。
