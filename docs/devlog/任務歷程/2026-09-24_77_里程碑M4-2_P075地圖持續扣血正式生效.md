- Java `World.handleMap`：`map.characterSize() > 0` 時 `boolean hurt = map.canHurt()`（每張圖每 tick 算一次，空圖不推進週期）。
- Java `handleCooldowns`：`if (chr.isAlive()) { … if (hurt) { if (EQUIPPED.findById(map.getHPDecProtect()) == null) {
  if (mapId == 749040100 && CASH.findById(5451000) == null) addHP(-dec); else if (mapId != 749040100) addHP(-dec); } } }`。
- Java `addHP` → `PlayerStats.setHp`：夾在 [0, maxHp]；由活轉死時先 `enableActions` + `playerDead()`，回到 `addHP` 再 `updateSingleStat(HP)`。
- `playerDead()`（經驗值損失、護身符、取消 buff…）MapleForge 所有死亡路徑都沒有，屬獨立缺口，本 P 不做（留 P076+）。
- `setHp` 非 silent 時的 `updatePartyMemberHP`（隊伍血條）一般受傷路徑同樣未接，不在本 P 範圍。
