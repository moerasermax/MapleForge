# MapleForge — 任務追蹤清單

> 本清單是**唯一真相來源（single source of truth）**：你用來追蹤進度、我用來執行。

## 如何使用
- 每個任務一行，勾選框即狀態：`- [ ]` 未完成 / `- [x]` 完成。
- 進行中／阻塞用狀態標記：🟦 進行中、🟥 阻塞（後面註明卡在什麼）。
- 欄位：**ID** ｜ 標題 ｜ **DoD**＝驗收標準（達到才算完成）｜ **依賴** ｜ **大小**(S<1天 / M 1–3天 / L 3天+)。
- 改動規則：開始一個任務→標 🟦；完成→打勾並更新儀表板；卡住→標 🟥 並寫原因。
- **追蹤三層**：①本清單＝狀態真相來源 ②每完成一任務 `git commit` 訊息**帶任務 ID**（如 `M1-3: AES-OFB cipher 通過黃金測試`）＝可驗證帳本 ③`進度日誌.md`＝敘事紀錄。三者由 AI 在交付時順手同步，作者不需額外維護。
