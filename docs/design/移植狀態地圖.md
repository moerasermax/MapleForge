# MapleForge — v113 移植狀態地圖

> 以 Java `recv.properties` 的每個 opcode 為單位，逐條追蹤移植狀態。
> 狀態圖例：✅ 已接 dispatch 且有 handler ｜ 🟦 有程式碼/常數但未接 dispatch 或功能不完整 ｜ ❌ 完全未移植 ｜ 🚫 Java 也 disabled/註解掉
>
> 最後更新：2026-06-17（master HEAD `cc99ce3`，462 測試綠）

| 狀態 | 數量 |

## 未移植優先建議

### P0 — 解鎖核心遊玩體驗
1. **寵物系統**（8 opcode）— 寵物是 v113 最常用功能之一
2. **召喚獸系統**（4 opcode）— 多職業核心技能
3. **ENTER_CASH_SHOP**（1 opcode）— 進商城模式切換
4. **NPC_ACTION**（1 opcode）— NPC 動畫回放，沒它 NPC 站著不動
5. **CHANGE_MAP_SPECIAL**（1 opcode）— Script portal，部分地圖傳點靠這個
6. **USE_SKILL_BOOK**（1 opcode）— 三四轉技能書
7. **DELETE_CHAR**（1 opcode）— 基本登入功能

### P1 — 社交完整度
8. **家族系統**（9 opcode）— 完整社交但低使用率
9. **聯盟**（2 opcode）— 公會聯盟
10. **信差 / 留言**（2 opcode）
11. **DENY_PARTY_REQUEST**（1 opcode）
12. **USE_DOOR**（1 opcode）— 傳送門

### P2 — 進階內容
13. **雇用商人**（3 opcode）— 經濟系統
14. **合成 ITEM_MAKER**（1 opcode）
15. **MTS 拍賣**（3 opcode）
16. **活動/小遊戲**（~7 opcode）
